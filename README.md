# HRMS – Human Resource Management System

## Overview

The **Human Resource Management System (HRMS)** is designed to digitize and streamline core HR operations. It provides a centralized platform for managing employee information and simplifying everyday HR workflows.

## Key Features

* Employee onboarding and profile management
* Attendance tracking
* Leave management and approvals
* Payroll visibility
* Admin and HR officer workflows
* Employee and HR data management

## Purpose

The system aims to reduce manual HR processes, improve data accessibility, and provide efficient, transparent, and organized management of employee-related operations.
